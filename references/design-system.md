# 专业工作台设计规范

## 定位

参考入口：https://www.radix-ui.com/themes 。用户指定“非常像”时，先保留官网的构图与比例，再替换原创内容与品牌；不分发官方字体或标识。已有库优先；视觉 token 可适配 Vue、React、服务端模板或原生页面。

## 官网参考签名

2026-10-29 源 HTML/CSS 观察：桌面1280px以上为左右分栏，左文字区约560px并带64px附近内边距；右侧是比视口宽的多列组件集合，不是单张仪表盘截图。第一列团队/通知等宽卡约640px原始尺寸，经0.75比例呈现；右侧卡片交错排列。窄屏左文案在上，组件集合在下，可横向浏览。主标题是 Adobe Text Pro 衬线，不是通用后台sans；替代选用有许可的 Libre Caslon Display。正文和组件是中性sans。默认indigo强调色，白灰画布，半透明面板与细边界；不是青绿单色系统。

- 保留：大型常规字重衬线H1、多行紧凑行距、版本小标签、真实代码块、黑色主按钮/浅色次按钮、可操作的组件墙。
- 组件墙：团队邀请、通知开关、注册表单、付款卡、发票、活动、待办。内容换原创，整体尺寸、排列密度和边界语言稳定。
- 交互主题：强调色使用色板圆点，明暗用太阳/月亮图标，圆角用选择器。所有选项同步改变组件，不只换按钮高亮。
- 不要：用订单表格替代官网首页、给首页添加侧边导航、全页绿色、圆角大胶囊卡、英雄区渐变背景或插画替代组件。

## 模式选择

**官网式展示**：取 `docs/index.html` / `styles.css` / `app.js` / `tokens.css`，先对齐标题占比、左栏宽度、右栏卡片密度与裁切。示例的卡片是独立的交互组件，不是把页面大区套成卡片。

**应用工作台**：取 `docs/workspace/`，使用下面业务规范。保留组件精细边界、统一间距和中性色，但不要把官网大型衬线H1搬进数据工具。首页token与旧工作台token各自完整；不要混用变量名称。

相比 Resend Precision，辨识度不依赖代码、黑色界面或开发者术语，而来自高频操作的布局秩序。相比 Craft Clarity，优先密度、状态和批量处理，不把表格改成稀疏内容卡片。

## 应用工作台的主题与比例

可移植变量见 `../assets/tokens.css`。根元素加 `data-style="calm-console"`；同一元素加 `data-theme="dark"` 启用深色。它不是 Radix 库内部变量，可手动映射至现有主题。

| 项目 | 默认规则 |
| --- | --- |
| 色彩 | 中性白灰 / 中性深灰；默认indigo且可替换；成功绿、警告赭黄、危险红 |
| 字体 | 系统无衬线与中文回退；正文 15-16px，辅助字 13-14px，页标题 24-28px |
| 间距 | 4 / 8 / 12 / 16 / 24 / 32px；页边桌面 24-32px，窄屏 16px |
| 结构 | 导航 224-256px；详情侧栏 320-400px；主区 min-width: 0 |
| 控件 | 默认高 36px；舒适模式/主要触屏目标至少 44px |
| 表格 | 常规行 44-48px，紧凑行 36-40px；多行内容允许行高增长 |
| 边界 | 1px；圆角 4-6px；阴影用于菜单/弹层，不是每个页面区 |

字号不随 vw 变化，letter-spacing 保持 0。先通过结构降低密度，再考虑字重和留白；不要缩小正文解决拥挤。默认文本与表面保持 4.5:1，对交互边界和焦点使用明显强于装饰分隔的颜色。

## 布局配方

### 列表管理

应用导航 > 页面标题与主动作 > 筛选工具栏 > 数据表格 > 分页。主要动作最多一个突出，导出等低频动作收进菜单。列宽根据内容语义设置，数字右对齐，操作列固定宽度。宽表格可以在其区域横向滚动；移动端保留关键列，详情可展开，不能直接隐藏用户决策所需数据。

### 表单编辑

按业务含义分节，以分隔线和小标题组织，不用多层卡片。宽屏可用 2 列，仅把有自然关联的短字段并排；窄屏单列。标签一直可见，单位与帮助文字就近。保存区位置稳定，校验失败滚动/聚焦到首个错误，保留输入。未保存离开提示只在确实有更改时出现。

### 仪表盘

先呈现异常、待办和可采取的行动，再呈现趋势。统计项必须有时间范围、单位与数据来源上下文；不要为了装饰生成虚假图表。图表需使用真实数据或标注演示数据，提供可读标签和非颜色区分。主图周围不堆无关卡片。

### 轻量项目

若任务只需要一个表单或简单清单，保留一致控件和状态即可，省去侧栏、顶栏和多页导航。不要把每个项目都扩写为管理系统。

## 组件契约

- 导航：当前项有位置/字重/颜色的组合提示；折叠后图标仍有可访问名称；菜单内无当前页死链。
- 表格：排序显示方向，筛选可清除，分页变化保留合理筛选；批量选择明确表示“本页”或“全部结果”。执行后同步选择与统计。
- 搜索：使用真实可检索内容；请求异步时处理加载、过期响应与空结果；前端本地搜索不假装连接远端。
- 表单：错误写在字段附近且可由读屏关联；禁用和只读有不同含义；保存中防重复操作，失败保留内容。
- 对话框：标题与用途明确，焦点可见且受正确管理；关闭后返回触发元素。破坏性动作清楚写影响，按任务风险选择确认或撤销。
- 通知：不抢主焦点；状态变化用适当 live region；重要错误不只靠短暂 toast。
- 图标：延续已有图标库，新项目优先 Lucide；不手绘已有标准工具图标。图标按钮提供名称与必要 tooltip。

## 验收

在 375px、768px、1440px 检查导航、长列名、长用户名、错误信息和弹层。验证主任务的完整闭环，并覆盖键盘、空数据、加载、失败与成功。只有任务确实实现两种主题时才宣称支持明暗切换；token 包不等于完成的组件系统。
